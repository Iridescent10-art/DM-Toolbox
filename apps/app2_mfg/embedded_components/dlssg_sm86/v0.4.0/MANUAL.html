DLSSG 安装手册

本项目让 RTX 20 / 30 显卡也能开 DLSS 帧生成，RTX 40 / 50 默认换用本项目的帧生成内核；RTX 30 / 20 还可以打开本项目的 INT8 超分内核。照着下面的步骤一步一步做就行，每一步都写了去哪里点、点什么。

中文 · English适用于 DLSSG 0.4.0 发布包全部设置的完整说明：docs\INSTALL.md
先看这三条
  1. 只支持 NVIDIA RTX 20 / 30 / 40 / 50 系列显卡。GTX 显卡、AMD 和 Intel 显卡都不能用。帧生成只支持 DirectX 12 的游戏。
  2. 带反作弊的联网游戏一律不要装，例如三角洲行动、永劫无间、漫威争锋、使命召唤、GTA5，有封号风险。
  3. 每次复制了文件、改了设置，都要完全退出游戏再重新打开才会生效。

步骤

  1. 准备：打开「硬件加速 GPU 计划」
  2. 解压发布包
  3. 找到游戏的 EXE 文件夹
  4. 复制文件
  5. 确认装上了
  6. 开始使用

另外：怎么改设置文件 · 升级 · 卸载 · 常见问题（包括游戏不认 version.dll 时怎么办）

1

准备：打开「硬件加速 GPU 计划」

帧生成要求 Windows 的「硬件加速 GPU 计划」是打开的。它关着的话，所有游戏的帧生成选项都打不开。

  1. 点开始菜单，输入 图形设置，打开搜到的那一项（Windows 11 里这一页叫「显示卡」）。
  2. 找到 硬件加速 GPU 计划，把开关打开。Windows 11 要先点「更改默认图形设置」（有的版本叫「高级图形设置」）才能看到它。
  3. 如果是刚打开的，重启电脑。本来就是开着的就不用管。

另外两件事：

  • 显卡驱动尽量更新到最新版（在 NVIDIA App 或 GeForce Experience 里更新）。
  • 这个游戏如果装过别的改 DLSS 或帧生成的 MOD（例如 OptiScaler、DLSS Enabler、其它版本的 dlssg-to-fsr3），先按那个 MOD 的说明卸载掉。
2

解压发布包

  1. 右键发布包的 zip 文件，选 全部解压缩，再点「解压缩」。用 7-Zip、WinRAR、Bandizip 解压也可以。
  2. 一定要先解压，不要在压缩包里直接拖文件。

解压出来的文件夹里，只有下面标出来的 3 样要复制到游戏里，其它的先不用管：

解压出来的文件夹\
├─ version.dll
├─ dlssg_sm86.ini
├─ dlssg_sm86\             （整个文件夹）
├─ alternatives\            游戏不认 version.dll 时才用，见「常见问题」
├─ MANUAL.html              你正在看的这份安装手册
├─ README.md                版本说明，可以用记事本打开
└─ docs\ 和其它几个文件     不用管
3

找到游戏的 EXE 文件夹

文件要放在游戏真正运行的那个 EXE 旁边。很多游戏的安装目录里只有启动器，真正的 EXE 在更深的文件夹里，放错了地方就不会生效。

最稳的找法（所有游戏都适用）

  1. 正常启动游戏，进到主菜单。
  2. 按 Ctrl + Shift + Esc 打开任务管理器，点「详细信息」。
  3. 找到游戏的进程（名字一般和游戏名相近，CPU 和内存占用最高的那个通常就是），右键，选 打开文件所在的位置。
  4. 弹出来的这个文件夹就是要放文件的地方。先别关这个窗口，然后完全退出游戏。

几个常见游戏

在 Steam 库里右键游戏 →「管理」→「浏览本地文件」，再往里进到下面这一层：

游戏EXE 所在的文件夹
巫师 3：狂猎The Witcher 3\bin\x64_dx12

4

复制文件

  1. 先看一眼游戏文件夹里有没有这几个文件：version.dll、winmm.dll、dbghelp.dll、dinput8.dll、dxgi.dll、d3d12.dll。
    • 一个都没有：直接做下一步。
    • 有，而且是你以前装本项目时放进去的：做下一步，把旧的删掉。
    • 有，但不知道是什么（多半是别的 MOD）：在桌面新建一个文件夹，叫「游戏备份」，把这些文件剪切进去，卸载本项目时再放回来。
  2. 以前装过本项目（任何版本）的：先把游戏文件夹里旧的 version.dll、winmm.dll、dbghelp.dll、dinput8.dll、dlssg_sm86.ini 和 dlssg_sm86 文件夹都删掉（旧版本会放四个 DLL，现在只用一个）。旧的 dlssg_sm86.ini 改过设置的话，先记下改了什么，装好后在新的里面重新改。
  3. 回到解压出来的文件夹，按住 Ctrl 依次点选这 3 样：version.dll、dlssg_sm86.ini、dlssg_sm86 文件夹，然后按 Ctrl + C。
  4. 切到游戏文件夹，按 Ctrl + V。如果提示「替换或跳过文件」，选 替换目标中的文件。

复制好以后，游戏文件夹里应该是这样：

游戏 EXE 所在的文件夹\
├─ （游戏自己的 EXE 和其它文件，不要动）
├─ version.dll
├─ dlssg_sm86.ini
└─ dlssg_sm86\
   ├─ backend\
   ├─ kernels\
   ├─ runtime\
   └─ sr\
一次只放一个 DLL

本项目靠 version.dll 这一个文件挂进游戏。绝大多数游戏用它就行；个别游戏不认它时，换成 alternatives 里的另一个（见换一个 DLL 试），但任何时候游戏文件夹里只放一个。三样东西也必须放在一起：只复制 DLL、不复制 dlssg_sm86 文件夹，什么都不会发生。

5

确认装上了

  1. RTX 20 / 30：启动游戏，打开图形设置。原来是灰的或者没有的「DLSS 帧生成」现在能打开了，就说明装上了。
  2. RTX 40 / 50（帧生成本来就能开），或者想确认得更清楚：
    1. 按怎么改设置文件，把 [Logging] 下面的 Level=1 改成 Level=2，保存。
    2. 启动游戏，打开帧生成玩一两分钟，完全退出游戏。
    3. 打开游戏文件夹里的 dlssg_sm86\logs。里面有 loader_一串数字.jsonl 这样的文件，就说明装上了。
logs 是空的很正常

出厂设置 Level=1 只在出错时写日志，所以没改成 2 之前，dlssg_sm86\logs 是空的，或者根本没有这个文件夹，都是正常的。确认完可以改回 1，也可以一直用 2（日志会多一些）。

Level=2 下开了帧生成，logs 里还是没有 loader_ 开头的文件：说明没装上。先确认放对了文件夹，再按换一个 DLL 试做。

6

开始使用

6.1 帧生成 所有 RTX 显卡

  1. 在游戏的图形设置里打开 DLSS 帧生成（有的游戏叫 DLSS Frame Generation 或「DLSS 多帧生成」）。倍数（2X / 3X / 4X）在游戏里选，游戏给什么就能选什么。
  2. 出厂最多 4X。游戏菜单里有 6X 或「动态」多帧生成，又想用 6X 的话：按怎么改设置文件，把 [FrameGeneration] 下面的 MaxGeneratedFrames=3 改成 5。游戏自带的帧生成组件只支持 4X 的话，改了也还是 4X。
  3. 帧生成要有足够的基础帧率才好看：关掉帧生成时帧率太低的话，开了以后容易有拖影、边缘破碎，倍数越高越明显。这时先降低画质，把基础帧率提上来。
RTX 40 / 50 注意

第一次打开帧生成时画面会卡住几秒，这是驱动在编译本项目的内核，以后就不会了；更新驱动后第一次还会再卡一次。这是正常的。

游戏里能选的倍数由游戏决定，本项目不改（例如 RTX 40 上很多游戏只给 2X）。想换回 NVIDIA 官方的帧生成内核：在 [Compatibility] 下面加一行 AccelerateNewerGpus=0。

6.2 超分 INT8 只限 RTX 30 / 20

出厂是关着的（[SuperResolution] 下面是 Mode=Off）。RTX 40 / 50 跳过这一节：本项目在 40 / 50 上不改超分，改成 On 也不起作用。

  1. 按怎么改设置文件，把 [SuperResolution] 下面的 Mode=Off 改成 Mode=On，保存。
  2. 在游戏的图形设置里，把 DLSS 超分辨率（有的游戏叫「DLSS 超级分辨率」或「超分辨率模式」）设成 性能 或 超级性能。多数游戏里只有这两档会用到本项目的 INT8 超分，「质量」「平衡」「DLAA」照常是 NVIDIA 自己的。
  3. 游戏里如果有 DLSS 光线重建，要关掉：它开着时游戏不用超分，这一项不起作用。
  4. 用 NVIDIA App 的话：如果在 NVIDIA App 里给这个游戏设置过 DLSS 覆盖（模型预设），先关掉，或者选「最新」。
一次只用一档

同一次游戏里，「性能」和「超级性能」只有先用上的那一档会加速。想换另一档：在设置里改好，完全退出游戏，再重新打开。直接在游戏里来回切换的话，后切的那一档这一次不会加速。这不是故障。

打开以后，游戏的 DLSS 超分会换成随包的版本（310.7.129）。游戏自带的版本比较旧时，画面和帧率的变化不全来自 INT8。

6.3 其它设置 一般不用改

都在 dlssg_sm86.ini 里，改法见怎么改设置文件。「不写」的设置要自己在那一节下面加一行。

设置在哪一节出厂什么时候改
Optimized[DLSSG]2帧生成的加速档位。生成的画面有问题时改成 1 试试（这一档的画面和不做任何加速时完全相同）；0 是不做任何加速。旧版本的设置文件把它写在 [FrameGeneration] 下面，照样有效。
MaxGeneratedFrames[FrameGeneration]3（最多 4X）要 6X 时改成 5（见 6.1）。
Preset[DLSSG]Auto改成 C = 轻量帧生成（FG Lite）：每个生成帧的 GPU 时间约少三成到一半，画质略低（主要在 HUD 和物体边缘）。同样用本项目的加速内核，游戏自带哪个版本的 DLSS-G 都能用。B（强制 UI 重组）只在游戏同时提供无 HUD 画面和 UI 平面时才有效，多数游戏不提供，这时日志里有一条 preset_ineffective。
Engine[FrameGeneration]DLSS改成 XeSS = 用 Intel XeSS-FG 的模型生成插帧（只 2X）。在 RTX 30 上它比默认的 DLSS 慢（4K 每生成帧多约 3 ms），也多占约 0.4–0.5 GB 显存；游戏后缓冲是 RGBA16F（部分 HDR 输出）时自动用回 DLSS。见 6.4。
Mode[SuperResolution]OffRTX 30 / 20 想用 INT8 超分时改成 On（见 6.2）。
Level[Logging]1（只记错误）确认安装、反馈问题时改成 2。
FrameTiming[Logging]不写（关）想记录每一帧的耗时（帧间隔、超分和帧生成各花了多少 GPU 时间）时加一行 FrameTiming=1，日志里会多一个 frames_ 开头的文件。
AccelerateNewerGpus[Compatibility]不写（开）RTX 40 / 50 想换回 NVIDIA 官方帧生成内核时加一行 AccelerateNewerGpus=0。

其它设置都不在出厂文件里，一般用不到，完整说明见 docs\INSTALL.md（可以用记事本打开）。

6.4 XeSS 帧生成（可选） 所有 RTX 显卡

按怎么改设置文件，把 [FrameGeneration] 下面的 Engine=DLSS 改成 Engine=XeSS。游戏里照常打开 DLSS 帧生成，倍数只有 2X（设置文件里写了更高也按 2X）。[XeSSFG] 一节有两项：FlowResolution（Coarse / Middle / Fine，出厂 Middle，越细越慢）和 UseHudless（出厂 1：游戏提供无 HUD 画面时用它，没有就自动不用）。[DLSSG] 一节的设置在 XeSS 下不起作用。

游戏的后缓冲是 RGBA16F（部分 HDR 输出用这种格式）、或者缺 XeSS 需要的输入时，这个游戏改用 DLSS 帧生成，日志（出厂级别就有）里有一条 xefg_fallback 写明原因。

7

遇到问题怎么反馈

  1. 按怎么改设置文件，把 [Logging] 下面的 Level 改成 2（已经是 2 就不用改）。
  2. 先把 dlssg_sm86\logs 里原来的文件删掉，再启动游戏，把问题复现一次，然后完全退出游戏。
  3. 把游戏文件夹里的 dlssg_sm86\logs 整个文件夹压缩：右键 logs →「压缩为 ZIP 文件」（Windows 10 是右键 →「发送到」→「压缩(zipped)文件夹」）。
  4. 把这个压缩包，连同下面这段填好的文字，提交到你下载本项目的地方（例如 GitHub 页面的 Issues）。
  5. 画面问题附上截图或录屏：截图按 Win + Shift + S，录屏按 Win + Alt + R。

怎么改设置文件

所有设置都在游戏文件夹里的 dlssg_sm86.ini 里（改解压出来的那一份没有用）。

  1. 完全退出游戏。
  2. 在游戏文件夹里右键 dlssg_sm86.ini →「打开方式」→「记事本」。Windows 11 可能要先点「显示更多选项」。
  3. 找到方括号里的那一节，例如 [Logging]，在它下面找到要改的那一行，只改等号后面的值，例如把 Level=1 改成 Level=2。分号 ; 开头的行是说明文字，不用管。
  4. 要「加一行」的设置（例如 AccelerateNewerGpus=0）：写在对应那一节的方括号那一行下面、下一个方括号之前，单独占一行，不要写到别的节里。
  5. 按 Ctrl + S 保存，关掉记事本，再启动游戏。
改坏了也不要紧

写错的那一项会自动用回默认值，其它设置照常生效（日志里会记一条 configuration_warning）。想恢复出厂设置，从解压出来的文件夹里重新复制一份 dlssg_sm86.ini 覆盖过去。

升级

  1. 完全退出游戏。
  2. 和第 4 步一样：先删掉游戏文件夹里旧的 DLL（version.dll 或你换上的那个）、dlssg_sm86.ini 和 dlssg_sm86 文件夹，再复制新版的 3 样。
  3. 以前改过的设置，在新的 dlssg_sm86.ini 里重新改一遍。
  4. 从 0.3.x 升级的，还可以删掉 %LOCALAPPDATA%\DlssgSm86 这个文件夹（在文件资源管理器的地址栏里输入这串字回车就能打开），新版不再用它。

卸载

  1. 完全退出游戏。
  2. 删掉游戏文件夹里的 version.dll（换过 DLL 的，删你换上去的那一个）、dlssg_sm86.ini 和 dlssg_sm86 文件夹。
  3. 第 4 步备份过文件的，把它们放回去。
  4. 还不放心的话：Steam 库里右键游戏 →「属性」→「已安装文件」→「验证游戏文件的完整性」。它会恢复被覆盖的游戏文件，但不会删除多出来的文件，所以上面第 2 条一定要自己删。

常见问题

帧生成选项还是灰的，打不开

  • 确认第 1 步的「硬件加速 GPU 计划」已经打开，并且重启过电脑。
  • 确认文件放在了真正的 EXE 文件夹里（用第 3 步任务管理器的方法再找一次），三样东西都在。
  • 确认游戏本身支持 DLSS 帧生成，并且用的是 DirectX 12。
  • 还是不行：照第 7 步把日志发回来，日志里看得出原因。

Level 改成 2 了，logs 里还是什么都没有

  • 最常见的原因是放错了文件夹，按第 3 步重新找。
  • 文件夹没放错，就是这个游戏不认 version.dll，按下面「换一个 DLL 试」做。
  • 杀毒软件（360、火绒、Windows 安全中心等）可能拦截或删除了 version.dll 这些文件。本项目的 DLL 用的是自签名证书，有的杀毒软件会误报。去杀毒软件的隔离区或拦截记录里看看，恢复文件并加入信任。
  • Windows 11 的「智能应用控制」开着时也可能拦截。遇到这种情况请把情况反馈给我们，不建议为了用本项目去关它。

换一个 DLL 试

解压出来的 alternatives 文件夹里有另外 5 个名字的同一个程序。按下面的顺序一个一个试，每次游戏文件夹里只放一个：

  1. 完全退出游戏，删掉游戏文件夹里的 version.dll（或者上一次试的那个）。
  2. 从 alternatives 里复制下一个到游戏文件夹，顺序是：winmm.dll → dbghelp.dll → dinput8.dll → dxgi.dll → d3d12.dll。
  3. 启动游戏，打开帧生成玩一两分钟，退出，看 dlssg_sm86\logs 里有没有出现 loader_ 开头的文件（Level 要先改成 2，见第 5 步）。有了就用这一个，没有就回到第 1 条换下一个。

五个都试过还不行，就把情况反馈给我们。dxgi.dll 和 d3d12.dll 排在最后，是因为它们在游戏的画面渲染路径上，只在前面几个都不行时才用，两个不要同时放。

游戏打不开或者闪退

  • 先照「卸载」删掉本项目的文件，确认游戏本身能正常运行。
  • 游戏本身没问题的话，重新装上，把 Level 改成 2，复现一次闪退，然后按第 7 步把日志发回来，并说清楚在哪一步闪退。

生成的画面闪烁、花屏或者拖影

  • 先看基础帧率：关掉帧生成时帧率太低，开了以后拖影、边缘破碎是帧生成本身的表现，降低画质把基础帧率提上来再看。
  • 把 [DLSSG] 下面的 Optimized=2 改成 1 再试（这一档的画面和不做任何加速时完全相同）。
  • RTX 40 / 50：在 [Compatibility] 下面加一行 AccelerateNewerGpus=0 换回官方内核再试。
  • 还在的话按第 7 步反馈，写明哪些设置下出现、哪些设置下没有。

超分打开了，好像没变化

  • 只有 RTX 30 / 20 才有这一项，RTX 40 / 50 不改超分。
  • 游戏里的 DLSS 要设成「性能」或「超级性能」，「质量」「平衡」「DLAA」不受影响。
  • DLSS 光线重建要关掉；NVIDIA App 里给这个游戏设的 DLSS 覆盖要关掉，或者选「最新」。
  • 在游戏里切过档位的话，完全退出再进（见 6.2「一次只用一档」）。

改了设置好像没变化

  • 改完一定要完全退出游戏。可以在任务管理器里确认游戏进程已经没有了，再重新打开。
  • 确认改的是游戏文件夹里的 dlssg_sm86.ini，不是解压出来的那一份，并且按 Ctrl + S 保存了。

开了帧生成，操作感觉有点延迟

  • 帧生成会让画面更流畅，但操作延迟会比不开时略高一点，这是帧生成本身的特性。如果延迟大到明显影响操作，可以降低倍数，或者按第 7 步反馈。
